# 课桌便利贴

一块课桌上的便利贴墙：**整张纯色便签**。悬停时右上角翻面 / 销毁；快捷键改色。

- **红**：最紧急，墙上最多 3 张  
- **橙**：要做，但不赶  
- **绿**：长期、慢慢来  
- 数据在浏览器 `localStorage`，无登录

## 使用说明

### 选中

点一下便利贴，或在上面输入（光标在内），即视为**选中**。选中时阴影略加深。

### 翻面

悬停或选中时，点右上角 **背/正** 翻面；点 **垃圾桶** 触发撕碎动画飞入 **废纸篓**（等同 ⌘/Ctrl+O）。

### 快捷键

macOS 用 **⌘**，Windows / Linux 用 **Ctrl**。须先选中一张贴。

| 快捷键 | 作用 |
|--------|------|
| ⌘/Ctrl + **1** | 红色 |
| ⌘/Ctrl + **2** | 橙色 |
| ⌘/Ctrl + **3** | 绿色 |
| ⌘/Ctrl + **O** | 销毁（Over）：撕碎飞入右侧废纸篓 |

应用内点右上角 **「说明书」** 可再次打开完整说明（首次进入会自动弹出）。

### 鼠标操作

- **便签本**（左下角叠放的一沓）：点一下新建便利贴  
- **拖动**：在墙上挪动位置  
- **拖到右侧废纸篓** 松开：等同 ⌘/Ctrl + O  
- 废纸篓内可 **贴回墙上**；红贴已满时会提示先降一张
